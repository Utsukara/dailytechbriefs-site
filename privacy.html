Privacy policy

Last updated: 14 October 2026

What this covers

This policy covers this website and the private uploader application ("the application") that the operator of the Daily Tech Briefs and AllStreamClips YouTube channels uses to publish videos to those channels.

Who uses the application

Only the operator of those two channels, signed in with the Google account that owns them. It is not offered to the public.

What the application accesses

With the operator's consent, the application uses YouTube API Services to:

  • upload videos, with their titles, descriptions, tags and thumbnails, to the operator's own channels;
  • read the list and status of videos on those channels, so the same video is not uploaded twice and a removed video is noticed;
  • read statistics (view, like and comment counts) for videos on those channels.

It does not access any other person's Google or YouTube account, and it does not collect personal information about viewers, commenters or subscribers.

What is stored

On a private computer controlled by the operator: an authorization token for the operator's own account, the identifiers of the videos the application uploaded, and the statistics described above. This information is not sold, shared or transferred to anyone.

Visitors to this website

This website uses no cookies, analytics or tracking, and collects no information about visitors. It is hosted on GitHub Pages, whose own privacy terms apply to the hosting. People who watch the channels on YouTube are covered by YouTube's terms and the Google Privacy Policy.

YouTube API Services

The application uses YouTube API Services. See the YouTube Terms of Service and the Google Privacy Policy.

Revoking access and deleting data

Access can be revoked at any time on the Google account permissions page. Revoking it makes the stored token useless; the token and stored statistics are then deleted from the operator's computer.

Contact

Through the About page of the Daily Tech Briefs YouTube channel.
